# rdzeń

Trening, oddech i świadoma progresja. PWA do treningu mięśni Kegla, oddechu i uziemienia.

## Stack

- Vite + React + TypeScript
- Tailwind CSS
- IndexedDB (offline-first)

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run typecheck` — TypeScript type checking
- `npm run lint` — ESLint
